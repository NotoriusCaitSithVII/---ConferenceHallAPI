Наведена програма є API для для управління залами, бронюваннями та розрахунку вартості оренди.
Поставлені задачі вирішені за допомогою 4-ох форм, та були розроблені у середовищі Visual Studio на мові C# з використанням Windows Forms, з використанням Microsoft.Data.Sqlite та мови SQL для збереження даних.
Перша форма - форма створення зали. Користувач вводить дані (назва зали, максимальна кількість осіб, базова оренда) та обирає з таблиці які додаткові послуги входять до зали. Зала створюється по натисканні відповідної кнопки, і дані про неї заносяться у базу даних.
Друга форма - форма редагування зали. У цій формі користувач обирає залу через їх список у ComboBox, після чого інформація про неї завантажеється на таблицю. Користувач здатен редагувати дані в таблиці, при натисканні кнопки збережені дані оновлюються в базі даних.
Третя форма - форма оформлення оренди. У цій формі користувач обирає залу через їх список у ComboBox, після чого інформація про неї завантажеється на таблицю. Далі користувач обирає дату та час на який він бажає орендувати залу, в таблиці можна вибрати чи включати доступні функції, та здатен в реальному часі бачити бачити загальну суму яку має сплатити. Оформлення відбувається по натисканні кнопки, дані заносяться в базу даних.
Четверта форма - форма перегляду орендованих зал. Користувач не здатен взаємодіяти з цією формою, і може лише її переглядати.

Між першою, другою та третьою формою користувач може рухатись за допомого відповідних кнопок. Доступ до четвертої форми є лише з третьої форми

Свторення звітів та аналітики, нажаль реалізувати не зміг.
